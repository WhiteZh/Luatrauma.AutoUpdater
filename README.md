# Luatrauma.AutoUpdater
Windows:
```cmd
cmd /c "start /b Luatrauma.AutoUpdater.win-x64.exe -- %COMMAND%"
```
Linux:
```shell
bash -c "./Luatrauma.AutoUpdater.linux-x64 -- %command%"
```
Linux (Proton):
```shell
bash -c "./Luatrauma.AutoUpdater.linux-x64 --force-windows -- %command%"
```
MacOS:
```shell
/bin/zsh -c "./Luatrauma.AutoUpdater.osx-x64 -- %command%/Contents/MacOS/Barotrauma"
```
